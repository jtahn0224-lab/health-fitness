    ☁️ Firebase 실시간 온라인 서버 연동

    Firebase Cloud Firestore 및 Authentication(익명/교사 인증)을 연결하면 학생들이 각자 스마트폰이나 태블릿에서 입력한 기록이 교사용 통계 화면에 실시간으로 동기화됩니다.

    1단계: Firebase 콘솔에서 프로젝트 생성 후 Authentication(익명 로그인 허용)과 Cloud Firestore를 활성화합니다.
    2단계: 프로젝트 폴더의 firestore.rules 보안 규칙을 배포하거나 콘솔 Rules 탭에 붙여넣습니다.
    3단계: 웹 앱 설정의 firebaseConfig JSON(또는 키 값)을 아래에 붙여넣고 [서버 연결 시작]을 누르세요.
    현재 상태: 로컬 브라우저 저장소(localStorage) 모드로 동작 중입니다.
